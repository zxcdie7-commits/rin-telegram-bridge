# Рин — мост личного аккаунта Telegram ↔ Hermes

Рин — ИИ-помощница, которая живёт в **обычном пользовательском аккаунте Telegram** (не боте) и думает через
[Hermes Agent](https://github.com/NousResearch/hermes-agent). Мост на Telethon связывает аккаунт с Hermes:

- **Владелец** пишет или шлёт голосовые → полная Рин через Hermes (память, инструменты, компьютер).
  Рискованные действия Рин сначала спрашивает в чате: «Разрешить? да / нет».
- **Голос** — ElevenLabs `eleven_v4_turbo` с тегами интонаций (`[laughs]`, `[softly]`, `[sighs]`): они звучат, а не читаются.
- **Звонки Telegram** (py-tgcalls): владелец звонит Рин — она берёт трубку и говорит вживую; по просьбе владельца
  Рин сама звонит человеку, представляется ИИ-помощницей, ведёт разговор по поручению и присылает итог.
- **Чужие люди** (по желанию, `PUBLIC_MODE=1`) — упрощённая Рин без доступа к компьютеру, с лимитами, `/стоп`, блоком.
- **Отправка по приказу** — `send.py`: текст, голосовое, файл, гифка, звонок; лимиты на час/день/новых людей.

## Что нужно

- macOS (автозапуск через launchd; на Linux мост работает, но автозапуск придётся сделать через systemd)
- Python **3.12+** (py-tgcalls), `ffmpeg` в PATH (`brew install ffmpeg`)
- Запущенный **Hermes Agent** с включённым API-сервером (`API_SERVER_KEY` в `~/.hermes/.env`, по умолчанию порт 8642)
- Ключи в `~/.hermes/.env`: `API_SERVER_KEY`, `OPENROUTER_API_KEY` (упрощённая Рин, звонки), `ELEVENLABS_API_KEY` (голос)
- **Отдельный аккаунт Telegram** для Рин (не основной: за автоответы аккаунт могут ограничить)
- `api_id` и `api_hash` этого аккаунта — https://my.telegram.org/apps

## Установка

```bash
git clone <этот репозиторий> ~/rin-telegram-bridge
cd ~/rin-telegram-bridge
./setup.sh            # создаст venv и .env из примера
nano .env             # заполни: TG_API_ID, TG_API_HASH, ALLOWED_USERS (свой ID), OWNER_NAME, VOICE_ID
./setup.sh            # вход в аккаунт Рин по QR-коду и автозапуск
```

Вход по SMS-коду вместо QR: `venv/bin/python login.py`.

## Под себя

| Что | Где |
|---|---|
| Кто владелец, как его зовут | `.env`: `ALLOWED_USERS`, `OWNER_NAME` |
| Характер Рин для чужих и звонков | `persona_rin.txt` (обычный текст) |
| Жёсткие правила для чужих | `PUBLIC_SYSTEM` в `rin/config.py` |
| Голос | `.env`: `VOICE_ID`; модели — `rin/voice.py` |
| Модели (`/model iq`, `pro`, `local`) | `MODELS` в `rin/config.py` |
| Лимиты отправок и звонков | `.env` (`SEND_PER_HOUR`, `SEND_PER_DAY`, `SEND_NEW_PER_DAY`), `CALLS_PER_DAY` в `rin/calls.py` |

Характер полной Рин (для владельца) задаётся в самом Hermes — `~/.hermes/SOUL.md`. Чтобы она умела писать и звонить
с аккаунта, добавь туда, например:

```
У тебя есть свой личный аккаунт Telegram. Написать или позвонить человеку с него можешь ТОЛЬКО по прямой просьбе
владельца, через python3 ~/rin-telegram-bridge/send.py:
  send.py <@кому> "<текст>" · send.py --voice <@кому> "<текст>" · send.py --file <@кому> <путь>
  send.py --call <@кому> "<зачем звонишь>" — звонок голосом, итог придёт владельцу сообщением.
Никогда не открывай сессию Telethon сама.
```

## Команды владельца в чате с Рин

`/model iq|pro|local` · `/new` — новый разговор · `/status` · `/баланс` (OpenRouter) · `/блок @user` · `/разблок @user` · `/лог @user`

Голосовое → Рин отвечает голосовым. Текст со словами «голосом / гс» → тоже голосом.

## Голосовой модуль (необязательно)

Если на том же компьютере запущен голосовой модуль Рин с «слух-API» на `127.0.0.1:3012`
(`POST /hear` — float32 16 кГц → `{text, tone, turn}`, `GET /context` → `{mood, dota, voice_tags, tone_hint}`),
мост распознаёт голосовые и звонки через него: whisper large-v3-turbo, эмоция по голосу, смех, конец фразы.
Без него голосовые расшифровывает `stt.py` (faster-whisper small), а в звонках нужен именно он.

## Устройство

```
bridge.py        точка входа
rin/config.py    настройки (из .env), тексты правил
rin/app.py       Telegram-клиент и маршрутизация: владелец / поручения / чужие
rin/owner_runs.py  полная Рин через Hermes /v1/runs + подтверждения «да/нет»
rin/public.py    упрощённая Рин для чужих (OpenRouter), лимиты, гифки
rin/calls.py     звонки: распознавание кусками, ответ, голос кадрами по 10 мс
rin/voice.py     ElevenLabs v4 с тегами, обращение к голосовому модулю
rin/media.py     голосовые, медиа из ответов Hermes
rin/sender.py    сокет для send.py: отправки и звонки по приказу, лимиты
rin/commands.py  команды владельца
rin/storage.py   состояние чатов, блок/стоп
send.py          CLI для Hermes
stt.py           запасная локальная расшифровка
```

Логи — `bridge.log` (только счётчики, без текстов). Перезапуск:
`launchctl kickstart -k gui/$(id -u)/com.hermes.userbot`.

## Честно и безопасно

- Рин не притворяется человеком: в звонках представляется ИИ-помощницей, на прямой вопрос отвечает честно.
- Пишет и звонит первой только по приказу владельца, с лимитами. Не используй мост для рассылок и спама:
  Telegram банит такие аккаунты, а людям это неприятно.
- `.env`, `*.session` и переписки в git не попадают (`.gitignore`). Сессия Telethon = полный доступ к аккаунту — не делись ей.
